# Archify test fixtures

The `*.json` documents here are unmodified example IR files from the Archify
repository (https://github.com/tt-a1i/archify, commit
`a4065941f12be7967436261d9934784e381d423c`, version 3.2.0). One document per
supported diagram type. They are used by `render-service.test.ts` to check that
the vendored runtime delivers every type.
